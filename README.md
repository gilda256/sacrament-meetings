# Sacrament Meeting Planner

## Team Members
- Gilda (gilda256)

## Description
A Next.js application for planning and managing sacrament meeting agendas for wards.

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- SQLite (better-sqlite3)

## Features
- View all meetings
- View meeting details by ID
- View current/next meeting
- API endpoints for meetings data

## Setup
```bash
git clone [https://github.com/gilda256/sacrament-meetings](https://github.com/gilda256/sacrament-meetings)
cd sacrament-meetings
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
